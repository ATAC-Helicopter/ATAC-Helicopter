## Featured project

### [VaultSync](https://github.com/ATAC-Helicopter/VaultSync) — Backup you can understand and verify

[![VaultSync release](https://img.shields.io/github/v/release/ATAC-Helicopter/VaultSync?style=flat-square&label=release)](https://github.com/ATAC-Helicopter/VaultSync/releases/latest)
[![VaultSync stars](https://img.shields.io/github/stars/ATAC-Helicopter/VaultSync?style=flat-square&logo=github)](https://github.com/ATAC-Helicopter/VaultSync/stargazers)
![Platforms](https://img.shields.io/badge/Windows%20%7C%20Linux%20%7C%20macOS-333333?style=flat-square)
![.NET](https://img.shields.io/badge/.NET%2010-512BD4?style=flat-square&logo=dotnet&logoColor=white)

**VaultSync** is my main open-source project: a cross-platform desktop application for backing up and recovering project folders, workspaces, and files stored on local drives or NAS devices.

Instead of treating a successful backup job as proof that everything is safe, VaultSync puts **snapshots, integrity verification, restore previews, recovery drills, and readable history** in one workflow.

It's built with **C#, .NET, Avalonia UI, and SQLite**, and includes a CLI alongside the desktop application. The ongoing *Recovery Horizon* work is exploring more advanced system-recovery capabilities; bootable full-system recovery is not a stable general-purpose feature.
